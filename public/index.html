Recognised columns

Klaviyo campaign exports work as-is — Campaign Name, Campaign Channel, Total Recipients, Successful Deliveries, Unique Opens, Unique Clicks, Unique Placed Order, Revenue, Unsubscribes, Spam Complaints and Bounces are all recognised, and A/B variant rows are rolled up per campaign.

SMS campaigns: Klaviyo SMS exports work the same way (Total Recipients, Successful / Failed Deliveries, Unique Clicks, Unsubscribes, Revenue, Unique Placed Order). SMS has no opens, so open rate is shown for email only; delivery rate and click rate are the SMS engagement measures. An optional spend/cost column (e.g. SMS credit cost) adds ROAS and cost per order.
Channel: read from channel / Campaign Channel (Email, SMS, MMS, Text, Push…). If a file has no channel column, it is taken from the file name (e.g. klaviyo_sms_export.csv), then the campaign name, then from whether the row has opens (email) — inferred channels are flagged in the banner.

Recognised inputs (any subset): campaign, channel, sends/recipients, deliveries, failed deliveries, spend/cost, send_time, opens, clicks, orders/placed orders, revenue, unsubscribes, spam, bounces, sessions, add_to_cart, checkout (web funnel, if you have GA4/Shopify), discount_revenue, new_customers, period (current/baseline for vs-baseline deltas), verdict.
Headers are matched loosely (case / spaces / synonyms). Missing columns are skipped.

Google Sheets must be shared as Anyone with the link or Published to the web.
